# tuvi-web

The Thiên Hạc web app: a [Topcoat](https://github.com/tokio-rs/topcoat) app
that draws random Bản mệnh cards. It has no database.

Start it with `cargo up` from any folder in the repo, or with `topcoat dev`
from this folder (http://127.0.0.1:3000). Read the
[README in the repo root](../../README.md) for setup, folders and how to
contribute.
